# Conceitos Fundamentais

## Autenticação VS Autorização

- **Autenticação**: verifica a identidade do usuário e as informações apresentadas, como os papéis concedidos e a associação ao tenant. **Revela quem está usando o serviço**.
- **Autorização**: controla quais recursos o usuário tem acesso na aplicação, de acordo com os privilégios concedidos.
